# pikpaktui

[中文版本](./README.cn.md)

A TUI and CLI client for PikPak cloud storage — written in pure Rust. OpenClaw friendly. Browse, download, upload, stream, and manage your files from the terminal.

![pikpaktui](https://repo.x-cmd.io/pikpaktui.svg)

## Install
